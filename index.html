    Run history

    Every run you load is added here. The tool fits a straight line to log K against %B across this history (always excluding the 90% B point) and derives the minimum %B at which the last peak's tR would land on the tR spec. The solvent and temperature of each run are read from its file name, and the tool uses them to work out which selectivity parameter to change next.
