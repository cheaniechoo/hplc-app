Start: how do you want to develop the method?

The isocratic and gradient flow charts are two separate entries, each with its own dashboard, specification, files and decisions.

Isocratic

%B stays constant through the run. The flow chart goes equipment, retention (%B), selectivity (temperature, solvent, ligand), then efficiency (column and flow) once all the peaks are there.

Gradient

%B changes during the run. Start from a scouting gradient (5–100 %B in 20 min) and steer with gradient steepness (GS): cases G1 ↑, G1 ↓, G1 ✕, G2, G3 and G4.

Worked runs or a clean start

Worked fills in the full set of runs, with the specifications tested and the decision returned for each. Clear empties both dashboards and resets the specifications, so you can enter your own runs.

Glossary

Specification

These numbers come from your method's requirements, not from the file. Set them once.

The Rs floor is calculated for each 7-peak run from the tR, back-pressure and Rs specs (Awesome Calculator). This value is only used if a file lacks what that calculation needs.

Leave blank to let the tool derive this from the log K fit across your runs.

Small integration blips left in the export are removed and not counted as peaks; you are told which ones. Set 0 to keep every peak.

Your columns

Efficiency recommendations only use columns ticked here, with the same ligand as the run. It starts as the Monash column list (in the lab). Untick the ones you don't have and add any you could order; a column in the lab is preferred when two options both meet the specs. A Raptor (core-shell) column in the list switches the Rs floor to the SPP floor.

    Log K vs %B

    The tool fits a straight line to log K against %B across the retention runs and works out the minimum %B at which the last peak's tR would land on your tR spec. Any run that keeps R² below 0.99 is left out of the fit. The fit stops updating once retention is exhausted or the selectivity stage starts.

    Parameters

    Every parameter the user can set, the module that controls it, its usual range, and what it changes in the separation. The category tells you whether it acts on the chemistry (the interactions between the compounds and the phases) or on the mechanics (the flow, the packing, the shape of the bed). Click a row to see the full description of that parameter. Ranges for the column rows are the values offered in Build a column. Restek sources are in the row details.
